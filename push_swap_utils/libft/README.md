## Description
Libft consists of many functions recoded from the standard C library. The goal of libft is to
understand how these functions actually work and apply them to future projects that may require
functions from libft. There are three parts which includes different functions in the libft library.

Part 1 which includes the standard C library functions.
Part 2 which includes additional functions that are not within the standard C library functions.
Part 3 which includes functions that manipulates linked lists.

## Instructions
To compile the following files into the libft.a file. 
Run the command: make all

To remove the object files generated from make.
Run the command: make clean

To remove the object files and the libft.a file.
Run the command: make fclean

To recompile all the following files again.
Run the command: make re
